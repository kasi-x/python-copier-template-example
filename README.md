## 🛠️ Development setup


Prerequisites: Python 3.11 or later and [uv](https://docs.astral.sh/uv/).

```sh
git clone https://github.com/kasi-x/python-copier-template-example.git
cd python-copier-template-example
uv sync                      # create .venv and install everything (incl. dev deps)

pre-commit install           # install the git hooks (lint/format on commit)
```



### Run with Docker

The repository ships a multi-stage `Dockerfile` and, for web services, a
local compose stack. To build and run the containerised service:

```sh
docker build -t python-copier-template-example .
docker run --rm python-copier-template-example --version


```

See [Run in a container](https://kasi-x.github.io/python-copier-template-example/how-to/run-container) for details.
